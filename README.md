
# 🧠 Flutter Quiz App

A **simple and interactive quiz application** built with **Flutter**, designed to test your knowledge on various topics in a fun and engaging way.

---

## 🚀 Features

- 🎯 Multiple-choice questions  
- 🧾 Score tracking system  
- ⚡ Smooth and responsive UI  
- 🌐 Cross-platform support — runs on Android, iOS, Web, macOS, Linux, and Windows  

---

## 🗂️ Project Structure

Here’s a step-by-step breakdown of the important folders and files:

1. **`android/`** – Contains Android-specific build files and configurations.  
2. **`ios/`** – iOS-specific setup and configurations.  
3. **`lib/`** – Main source code of the app.  
   - Contains Dart files (UI screens, quiz logic, models, etc.).  
4. **`assets/images/`** – Stores image assets used in the quiz interface.  
5. **`test/`** – Unit and widget tests for the application.  
6. **`web/`** – Web build and entry point for browser support.  
7. **`windows/`, `macos/`, `linux/`** – Desktop platform configurations.  
8. **`pubspec.yaml`** – Project metadata and dependencies list.  
9. **`analysis_options.yaml`** – Linting and code analysis rules.
